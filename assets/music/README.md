Put royalty-free background music here (mp3 / m4a / wav / ogg). Only use tracks you are allowed to
use on YouTube, for example from the YouTube Audio Library (studio.youtube.com -> Audio library).

Per mood, use a subfolder: `neutral/`, `tense/`, `emotional/`, `uplifting/`, `playful/`.
Files directly in this folder are used for any mood. No music here = narration only.
